# Venue

A place where the event, or a part of it, happens.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: venue
name: Venue
plural: Venues
description: "A place where the event, or a part of it, happens."
fields: {}
capabilities: [container]
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], blocks: []}
look: { hue: earth, icon: map-pin, layer: structure }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `venue` |
| Naming | `(Program) <Name> . (Venue) <Title>.md` |
| Capabilities | `container` |
| Templates | `event` |
