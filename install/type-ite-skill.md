# Skill

An atomic task with no human checkpoint.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: skill
name: Skill
plural: Skills
description: "An atomic task with no human checkpoint."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], reads: [], writes: []}
look: { hue: air, icon: zap, layer: procedure }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `skill` |
| Naming | `(Program) <Name> . (Skill) <Title>.md` |
| Capabilities | none |
| Templates | `shard` |
