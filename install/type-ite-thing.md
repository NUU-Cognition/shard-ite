# Thing

A part of the system.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: thing
name: Thing
plural: Things
description: "A part of the system."
fields: {}
capabilities: [container]
connections: {next: [], uses: [], depends-on: [], owner: [], informs: []}
look: { hue: water, icon: box, layer: structure }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `thing` |
| Naming | `(Program) <Name> . (Thing) <Title>.md` |
| Capabilities | `container` |
| Templates | `general` |
