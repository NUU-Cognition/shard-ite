# Theme

One area of work that a person thinks in, such as a product or a question.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: theme
name: Theme
plural: Themes
description: "One area of work that a person thinks in, such as a product or a question."
fields: {}
capabilities: [container]
connections: {next: [], uses: [], depends-on: [], owner: [], informs: []}
look: { hue: sun, icon: compass, layer: direction }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `theme` |
| Naming | `(Program) <Name> . (Theme) <Title>.md` |
| Capabilities | `container` |
| Templates | `work` |
