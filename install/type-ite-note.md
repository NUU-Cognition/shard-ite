# Note

A note that explains a part of the system. It makes no claim, so it has no grounding.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: note
name: Note
plural: Notes
description: "A note that explains a part of the system. It makes no claim, so it has no grounding."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], blocks: [], supports: [], refutes: [], reports-to: [], reads: [], writes: [], part-of: [], option-of: [], answers: [], opposes: [], picked: [], acts-on: [], threatens: [], protects: []}
look: { hue: stone, icon: sticky-note, layer: notes }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `note` |
| Naming | `(Program) <Name> . (Note) <Title>.md` |
| Capabilities | none |
| Templates | `software`, `process`, `event`, `research`, `organisation`, `general`, `shard`, `software-mine`, `thinking`, `work` |
