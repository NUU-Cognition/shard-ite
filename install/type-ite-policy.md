# Policy

A rule that the process must obey.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: policy
name: Policy
plural: Policies
description: "A rule that the process must obey."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], blocks: []}
look: { hue: earth, icon: shield, layer: control }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `policy` |
| Naming | `(Program) <Name> . (Policy) <Title>.md` |
| Capabilities | none |
| Templates | `process` |
