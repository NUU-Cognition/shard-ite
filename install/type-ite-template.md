# Template

The form of one artifact that the shard writes.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: template
name: Template
plural: Templates
description: "The form of one artifact that the shard writes."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], reads: [], writes: []}
look: { hue: earth, icon: file-text, layer: form }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `template` |
| Naming | `(Program) <Name> . (Template) <Title>.md` |
| Capabilities | none |
| Templates | `shard` |
