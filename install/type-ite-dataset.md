# Dataset

A set of data that the research reads.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: dataset
name: Dataset
plural: Datasets
description: "A set of data that the research reads."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], supports: [], refutes: []}
look: { hue: teal, icon: table, layer: evidence }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `dataset` |
| Naming | `(Program) <Name> . (Dataset) <Title>.md` |
| Capabilities | none |
| Templates | `research` |
