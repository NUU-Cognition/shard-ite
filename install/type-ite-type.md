# Type

A Mesh type that the shard installs.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: type
name: Type
plural: Types
description: "A Mesh type that the shard installs."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], reads: [], writes: []}
look: { hue: earth, icon: shapes, layer: form }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `type` |
| Naming | `(Program) <Name> . (Type) <Title>.md` |
| Capabilities | none |
| Templates | `shard` |
