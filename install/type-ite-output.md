# Output

What the process gives out: a product, a record, or a message.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: output
name: Output
plural: Outputs
description: "What the process gives out: a product, a record, or a message."
fields: {}
capabilities: [has-claims]
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], blocks: [], supports: [], refutes: []}
look: { hue: sun, icon: log-out, layer: process }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `output` |
| Naming | `(Program) <Name> . (Output) <Title>.md` |
| Capabilities | `has-claims` |
| Templates | `process`, `research` |
