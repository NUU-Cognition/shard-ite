# Input

What the process takes in: a request, a form, or a material.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: input
name: Input
plural: Inputs
description: "What the process takes in: a request, a form, or a material."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], blocks: []}
look: { hue: teal, icon: log-in, layer: process }
```

## Properties

| Property | Value |
|----------|-------|
| Type id | `input` |
| Naming | `(Program) <Name> . (Input) <Title>.md` |
| Capabilities | none |
| Templates | `process` |
