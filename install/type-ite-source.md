# Source

A paper, a book, a person, or a site that gives evidence.

A part of a program can have this type. The type gives the fields, the capabilities, the connections, and the look of the part in Steel.

```type
format: steel-type/1
id: source
name: Source
plural: Sources
description: "A paper, a book, a person, or a site that gives evidence."
fields: {}
capabilities: []
connections: {next: [], uses: [], depends-on: [], owner: [], informs: [], supports: [], refutes: []}
look: { hue: earth, icon: book-open, layer: evidence }
```
